Drop files into the year folder matching this naming convention (used by `../index.html`):

- `1.jpg`, `2.jpg`, `3.jpg` — photos
- `1.mp4` — video

Same names in every year folder (`2012/`, `2017/`, `2022/`, `2026/`). Add more
by extending the `photos`/`videos` arrays in the `YEARS` config in `index.html`.
